# Детальна інструкція з розгортання (Deploy) на Railway

Цей проєкт налаштований так, що його можна розмістити на Railway з єдиного GitHub-репозиторію. Railway самостійно збере ваш бекенд і фронтенд.

## Крок 1. Запуште код на GitHub
Перш ніж щось робити на Railway, переконайтеся, що всі зміни знаходяться на GitHub:
```bash
git add .
git commit -m "chore: setup for railway deployment"
git push origin main
```

## Крок 2. Створення Бази Даних (PostgreSQL)
1. Перейдіть на [railway.app](https://railway.app/) та авторизуйтеся.
2. Натисніть **"New Project"**.
3. Виберіть **"Provision PostgreSQL"**.
4. Railway за кілька секунд створить вашу базу даних.
5. Натисніть на створену базу (квадратик PostgreSQL), перейдіть у вкладку **Variables**.
6. Тут ви побачите змінну `DATABASE_URL`. Вона нам знадобиться для бекенду.

## Крок 3. Створення Backend-сервісу
1. У тому самому проєкті Railway натисніть **"New" -> "GitHub Repo"**.
2. Виберіть ваш репозиторій `AleksZal/Future-job-test`.
3. Одразу після цього сервіс почне білдитися, але нам треба змінити налаштування:
   - Натисніть на новий сервіс (це ваш бекенд).
   - Перейдіть у вкладку **Settings**.
   - Знайдіть секцію **"Root Directory"** і впишіть туди `/server`. Це скаже Railway шукати Dockerfile саме там.
   - Знайдіть секцію **"Networking"** -> **"Public Networking"** та натисніть **"Generate Domain"**. Скопіюйте цей домен (наприклад, `backend-xyz.up.railway.app`), він знадобиться для фронтенду!
   - Перейдіть у вкладку **Variables**.
   - Натисніть **"New Variable"**.
   - Додайте змінну: 
     - Name: `DATABASE_URL`
     - Value: `{{Postgres.DATABASE_URL}}` (Railway запропонує вам автоматично підставити її зі створеної раніше бази).

Після цього бекенд автоматично перезбереться і почне працювати!

## Крок 4. Створення Frontend-сервісу
1. У тому самому проєкті Railway знову натисніть **"New" -> "GitHub Repo"**.
2. Знову виберіть ваш репозиторій `AleksZal/Future-job-test`.
3. Налаштуйте цей сервіс як фронтенд:
   - Натисніть на цей другий сервіс.
   - Перейдіть у вкладку **Settings**.
   - Знайдіть секцію **"Root Directory"** і впишіть туди `/client`.
   - Знайдіть секцію **"Deploy"** -> **"Custom Dockerfile Path"** і впишіть туди `Dockerfile.prod` (оскільки ми спеціально створили продакшен версію).
   - У секції **"Networking"** натисніть **"Generate Domain"** (це буде адреса вашого сайту).
   - Перейдіть у вкладку **Variables**.
   - Створіть нову змінну:
     - Name: `VITE_API_URL`
     - Value: Вставте домен вашого бекенду з префіксом `https://` (наприклад, `https://backend-xyz.up.railway.app`).

Railway збере ваш React-додаток і запустить його. 

## Готово!
Тепер у вас є:
- База даних PostgreSQL
- API Бекенд
- React Фронтенд (який автоматично робить запити до вашого API)

Кожного разу, коли ви з Георгієм будете робити `git push` на гілку `main`, Railway автоматично буде оновлювати і фронтенд, і бекенд без вашої участі (це і є CD - Continuous Deployment)!
